SELECTED EXAMPLES

Work samples

Examples of the way I structure test cases and communicate defects. These are illustrative samples, not claims of client work.

TEST CASETC-LOGIN-01

Login with invalid password

Precondition

A registered user account exists.

Steps
  1. Open the login page.
  2. Enter a valid email and an incorrect password.
  3. Select Login.
Expected result

Access is denied and a helpful error message appears.

BUG REPORTBUG-CART-01

Cart total does not update

Steps to reproduce
  1. Add two products to the cart.
  2. Remove one product.
Actual result

The total still includes the removed product.

Expected result

The total reflects only the products remaining in the cart.

CHECKLISTWEB-FORM-01

Form validation checklist

  • Required fields reject empty input.
  • Email format is validated.
  • Invalid data shows clear feedback.
  • Valid submission completes successfully.
  • Errors do not erase valid user input.
